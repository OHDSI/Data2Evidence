# Account activities

## Account details

You can click the Account tab to access:

- Details about your user account

- Legal documents (Terms of Use, Privacy Policy, and Imprint)

- Change your password

- Delete your account

- Sign out from the system

**Change password**

To change your password:

1. Click Change password.
2. In the fields, enter your old password and create a new password. Note: You can also click Generate to fill in a random password; the generated password is shown in plain text so you can copy it. Use the eye icon to show or hide the new password at any time.
3. Click Change to save the new password. The dialog closes and the confirmation message "Your password has been updated successfully" appears briefly at the top of the page.

If the password cannot be updated (for example, the old password is wrong), the dialog stays open and shows the error "Password update failed. Unable to update password. Please try again." Correct your input and click Change to retry.
