# Notebooks

You can click the Notebooks option to start Starboard Notebooks. These
are in-browser, literate notebooks. You can use Python code here to
analyse your cohorts or the dataset. You can:

- Create a new notebook

- Import an existing notebook

- Access other shared notebooks

**Note**: Starboard notebooks are not meant for intense processing and
analysis of large datasets. You should use your own environment to do
that.
