# Introduction

## About Data2Evidence

Data2Evidence is an open source end-to-end platform for managing
healthcare data and analyzing it for generating insights.

The platform stores structured and unstructured clinical information from various sources including electronic health records, lab records, image metadata, and even text documents like clinician notes. Users can ingest, monitor data quality, and store data with fine grained access control. Users can also explore data and request access to it. With the platform, users can also filter and group patients according to different attributes to create cohorts for research.

Using inbuilt notebooks, users can run lightweight statistical analyses on their cohort data. Pre-configured analyses can also be run for the cohort data with the capability to add additional analyses using a plugin concept.

## Intended use

This platform is a research tool intended to support research work. It is not intended to be used for diagnostic or thereapeutic purposes.

## Requirements

Ensure you are using an up-to-date version of a supported Web browser and your screen resolution is high
enough to display the entire application.

## User roles in Data2Evidence

User roles determine the tasks you can perform when you sign in to the
Data2Evidence platform. The key roles are:

-   **Viewer**: Can view and request access to datasets.

-   **Researcher**: Can view, build cohorts, and analyse datasets.

-   **Administrator**: Can edit datasets, add users, and perform other
    administrative tasks.
